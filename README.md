# Binary Playground

A minimalistic portfolio website showcasing digital ventures crafted by Jason Conroy.

## Overview

Binary Playground is a single-page website that presents a curated collection of web properties and digital projects. Built with semantic HTML5 and modern CSS3, the site features a clean, professional design with a focus on typography and usability.

## Featured Projects

- **[Frags.au](https://frags.au)** - Homegrown corals – Frag by Frag
- **[BrinyBits](https://brinybits.au)** - 3D Printed and Acrylic Bits for Your Reef
- **[Jetty Works](https://jetty.works)** - Manufactory by the sea

## Tech Stack

- HTML5 (Semantic markup)
- CSS3 (Custom properties, Flexbox, Responsive design)
- Google Fonts (Pixelify Sans & Inter)
- binary-analytics (first-party, cookieless analytics: `/a/s.js`, served by the nginx vhost)

## Design Features

- Minimalistic, professional aesthetic
- Responsive layout optimized for all devices
- Custom typography with Pixelify Sans for branding
- Warm charcoal accent color scheme
- Clean hover interactions and transitions

## Local Development

Simply open `index.html` in your browser. No build process or dependencies required.
